## Electron at a Glance

Electron is a Windows desktop application for executing Roblox Lua scripts. Its workflow keeps the main actions together: start the app, connect it with Roblox, and control script execution through the included interface. The client is designed with a lightweight layout for Windows 10 and Windows 11.

Alongside execution controls, Electron provides a 500+ script community hub, batch runs, a queue that remains available between sessions, and an automatic update system. It is intended for users looking for a Windows Roblox executor, Lua executor, or integrated script hub with a compact interface and no-key access.

## Frequently Asked Questions

**Which operating systems can run Electron?**  
The current release is intended for Windows 10 and Windows 11.

**Is an updater included?**  
Yes. Electron contains an auto-update engine designed to make release changes easier to manage.

**What does Electron provide beyond a basic executor?**  
In addition to execution, it offers a script hub, queue support, batch processing, and a debugger, creating a more organized workflow than a minimal loader.

**Does Electron eliminate account-related risk?**  
No. No project can promise that. Anyone using a script executor should consider Roblox rules and accept responsibility for their own use.

**Where does Electron keep scripts?**  
Queued and saved items use local storage within the application directory or the configured data location.
